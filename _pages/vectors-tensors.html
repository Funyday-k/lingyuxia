What survives a change of coordinates?

The geometric object
v belongs to one tangent space TₚM. Its components depend on the chart; the vector does not.
The scalar reading
dT(v) is one temperature-change rate for the same probe motion. Vector and covector components compensate.
The physical relation
Covariance keeps a law consistent across coordinate descriptions. It does not require each component to stay numerically unchanged.
From the experiments to precise definitions

1 · A tangent vector is a derivation

At p, a tangent vector maps smooth functions near p to real numbers. It is linear and obeys v[fh] = f(p)v[h] + h(p)v[f]. A curve γ with γ(0) = p produces v[f] = (d/dt)f(γ(t))|₀. Curves represent the same tangent vector when these derivatives agree for every smooth f. This construction needs no ambient space and no metric.

The first experiment uses γₐ(t) = (t, 0.55t + ½at²) in fixed metre-and-second units. At t = 0 every path has v = (1, 0.55) m/s. For Δt ≠ 0 the average velocity is (1, 0.55 + ½aΔt); Δt = 0 shows its exact limit. Velocity arrows use a one-second display scale. Reparameterizing a curve rescales its tangent: dγ/dλ = (dt/dλ)dγ/dt. The path alone does not specify a speed.

2 · The chain rule explains contravariance

In coordinates, ∂ᵢ means differentiation with respect to xⁱ at p; these operators form a basis of TₚM. Since v = vⁱ∂ᵢ, its components are vⁱ = v[xⁱ]. With Jᵃᵢ = ∂x′ᵃ/∂xⁱ, the chain rule gives v′ = Jv and ∂′ₐ = (J⁻¹)ⁱₐ∂ᵢ. The second experiment uses x = E x′, E = R(θ) diag(b,1), so J = E⁻¹. This is a passive change of labels, not an active rotation of the particle.

3 · Covectors live in the dual space

A covector α is a linear map TₚM → ℝ. The dual basis dxⁱ satisfies dxⁱ(∂ⱼ) = δⁱⱼ, so α = αᵢ dxⁱ and α(v) = αᵢvⁱ. Its components transform as α′ = J⁻ᵀα. Here T(x,y) = 20 + 2x + y K, with gradients 2 K/m and 1 K/m. A unit-speed probe reads dT/dt = dT(v). Under x = bx′, y = y′, v′ˣ = vˣ/b while (dT)′ₓ = 2b; their product is unchanged.

The differential dT is naturally a covector. Turning it into the gradient vector grad T requires a metric: (grad T)ⁱ = gⁱʲ∂ⱼT. The familiar perpendicular arrow uses this extra geometry. “Covariant components” (lower indices) and “covariance of a physical law” are related terminology, but are different statements.

4 · A tensor is a multilinear map

A tensor of type (r,s) at p takes r covectors and s vectors and returns a scalar, linearly in each input separately. Thus a (0,2) tensor takes two vectors. Its component matrix changes as G′ = J⁻ᵀGJ⁻¹. In the fourth experiment G = I, v = c(1,0), w = (cos β, sin β): g(v,w) = c cos β. With E = diag(b,1), G′ = diag(b²,1) and the transformed components give exactly the same pairing. Scaling either input scales the answer; setting one input to zero makes it zero.

A matrix can represent a tensor after bases have been chosen; the transformation rule is essential. A tensor field assigns a tensor smoothly to each point. Vectors at different points lie in different tangent spaces; comparing them requires additional structure such as a connection. In GR the spacetime metric is Lorentzian, not the positive-definite Euclidean metric used in this diagram.

5 · Covariance belongs to the full equation

For the last experiment take the Euclidean plane, a dimensionless affine parameter t, and x=t, y=0.35t. Relabel it by X=x, Y=y+κx². This smooth map has determinant one and inverse x=X, y=Y−κX². The chain rule gives dY/dt=0.35+2κt and d²Y/dt²=2κ, even though the physical motion is unchanged. Ordinary coordinate acceleration is therefore not a vector under general nonlinear coordinate changes.

The transformed metric is dℓ² = dX² + (dY − 2κX dX)². Its only nonzero connection coefficient is ΓYXX = −2κ. Since dX/dt=1, the Y equation is 2κ−2κ=0. The covariant acceleration ∇ᵥv is still zero. The connection is not itself a tensor, and nonzero connection coefficients do not imply nonzero curvature: this plane remains flat.

Covariance means descriptions transform consistently, so they express the same physical relation. It does not say that all observers measure the same energy or frequency: changing the observer changes the physical measurement. Nor does a coordinate change create gravity. For a timelike worldline in GR, the four-velocity is the tangent u = dγ/dτ, using proper time τ; the same tensor reasoning extends to four-dimensional spacetime.
