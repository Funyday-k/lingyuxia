每一枚自旋，只看最近的四位邻居。

H = −J ∑⟨i,j⟩ sisj − h ∑i si

Ising（伊辛）模型把磁性简化为两态变量：si = +1 或 −1。这里演示经典模型；箭头只代表状态。

① 两种状态。箭头向上或向下，不连续旋转。

② 邻居互动。J > 0 时同向能量更低；J < 0 时反向更低。每对邻居只计一次。

③ 外场偏好。h > 0 偏好向上；h < 0 偏好向下。

所选自旋：第 17 行，第 17 列

ΔH = 2si(J ∑邻居 sj + h) = 0

接受概率
100%

Metropolis 规则：降低或不改变能量的翻转总被接受；增加能量时，以 e−ΔH/T 的概率接受。

点击按钮会暂停模拟，抽取随机数并决定是否翻转。

低温 · 成团
高温 · 杂乱

能量想要整齐，熵偏爱更多可能。

对于 J = +1、h = 0 的二维方格模型，低温平衡态倾向于选择一个整体方向；高温时两种方向混杂。温度越高，越容易接受需要付出能量的翻转。

Tc = 2 / ln(1 + √2) ≈ 2.269

磁化 m = Σsi / N：+1 表示全向上，−1 表示全向下，0 表示两种状态数量相等。

零磁化也可能有序：反铁磁可以形成棋盘格。此时看交错磁化 ms = Σ(−1)x+ysi / N；|ms| 接近 1 才说明整体交错有序。

临界温度公式对应无限晶格、零外场与铁磁耦合。有限窗口中的团簇和数值需要时间充分采样，不能把一帧当作平衡态。

有限晶格用于直观演示；严格的相变出现在热力学极限。调整参数后，曲线从新参数重新记录。

无量纲单位：kB = 1，能量以固定参考尺度为单位；这里的温度不是摄氏度。

方法与参考

二维 32 × 32 方格、周期边界、最近邻相互作用。每个 sweep 随机挑选 1024 次格点，依 Metropolis 概率尝试单自旋翻转。四边首尾相接，每个点始终有四位邻居。曲线展示即时构型的观测量，不是平衡平均值。随机重置保留当前参数并清空演化记录。

局部更新在低温或临界附近可能很慢；低温从随机态出发可能暂时困在多个磁畴中。演化速度只影响采样快慢，不改变接受规则。改变外场后，不应再把零场铁磁临界温度解释为当前系统的相变点。

原理：David Tong · Statistical Physics, §5；经典自旋：Statistical Field Theory, §1；算法：Metropolis et al. (1953)。
