首次连接

内容保存在你的 GitHub 仓库。只有拥有仓库写入权限的账号才能编辑；此入口页本身不包含私有内容。

1. 连接 GitHub 登录 待配置
  1. 在 Netlify 创建一个项目，用于提供登录认证。现有主页继续由 GitHub Pages 托管。
  2. 在 Netlify 的 Domain management 中添加 funyday-k.github.io，并保持它为 Primary domain，使认证结果能回传到现有后台。这里不修改 DNS；主页继续由 GitHub Pages 托管，Netlify 显示 Pending DNS verification 属于预期状态。
  3. 在 GitHub OAuth Apps 注册应用，主页填写本网站地址，回调地址填写 https://api.netlify.com/auth/done。
  4. 在 Netlify 项目的 Security → OAuth 中安装 GitHub Provider，将 Client ID 和 Client Secret 填入 Netlify。不要将密钥写入网站文件或聊天。
  5. 将 Netlify 的 Project ID 填入 _data/site_admin.yml 的 netlify_site_id，发布配置后即可登录。
查看官方设置说明 ↗
2. 连接私人统计 待配置
  1. 在 GoatCounter 创建站点，网站地址填写 https://funyday-k.github.io/lingyuxia/。
  2. 在站点设置中保持统计面板非公开，关闭公开访问及访客计数器。
  3. 将 你的名称.goatcounter.com 中的“你的名称”填入 _data/site_admin.yml 的 goatcounter_code。登录配置完成后也可在编辑器的“服务连接”中填写。

未填写有效站点名称时不加载统计脚本。本地预览与管理页不计入访问量。

日常使用与发布

进入编辑器后，选择栏目并新建或编辑内容。保存草稿后，在工作流中检查并发布；GitHub Pages 完成构建后，公开页面才会更新。草稿和附件也会写入公开仓库，请只上传准备公开的材料。建议单个附件不超过 10 MB。

已有交互笔记的实验代码保留在原页面；常规笔记可直接使用正文编辑器。笔记支持只上传 PDF、不填写正文。
